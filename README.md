# Aegis Edu Consultant

A production-ready, frontend-only web application designed for a premium educational consulting agency. Built with a strong emphasis on responsive architecture, type safety, and clean component design.

## Features

- **Fully Responsive:** Seamless experience across mobile, tablet, and desktop viewports.
- **Modular Architecture:** Feature-based component structure for scalability.
- **Type Safety:** Strictly typed with TypeScript.
- **Interactive UI:** Custom animations, hover states, and smooth scrolling.
- **Direct Contact Integration:** Native WhatsApp and Email routing via frontend form handling.

## Tech Stack

- **Framework:** React.js
- **Language:** TypeScript
- **Styling:** Vanilla CSS (CSS Variables, Flexbox, CSS Grid)
- **Build Tool:** Vite
